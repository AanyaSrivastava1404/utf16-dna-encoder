ABOUT APP

A web application for UTF-16 to DNA encoding using different modes, addressing the pressing need for long-term data preservation and archival methods. The application features various visualizations for an efficient user interface, aiming to meet the future demand for a portal that stores data not on any cloud or database, but in DNA.
